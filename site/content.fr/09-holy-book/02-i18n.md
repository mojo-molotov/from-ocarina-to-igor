
| Champ                     | Rôle                                                                                                                                     |
| ------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| `sticky: 1`               | Configuration obscure du thème, détail d'implémentation (`@sugarat/theme`)                                                               |
| `pagefind-indexed: false` | Exclusion de l'index Pagefind (souvent pour les pages concernant la "philosophie" qu'on ne veut pas voir polluer la recherche technique) |
| `description`             | Meta description (SEO + Open Graph)                                                                                                      |
| `date`                    | Date de publication (affichée + utilisée par le tri + déterminant l'ordre des chapitres à la génération en PDF)                          |
| `head.meta.og:image`      | Image de couverture (réseaux sociaux/aperçus OG lors de partages dans des chats + cards d'article)                                       |

## Traduction humaine

Les pages FR ne sont pas auto-traduites de l'EN.  
Elles sont **écrites séparément**, avec&nbsp;:

- Des tournures idiomatiques.
- Des références culturelles («&nbsp;_paquet de clopes_&nbsp;», «&nbsp;_r/AntiTaff_&nbsp;»).
- Des citations originales reprises telles quelles côté FR comme RU (comme «&nbsp;_In the Lulzboat, salute, bitch, and show some respect._&nbsp;» qui reste en anglais).

La **structure** et le **fond technique** sont identiques.

### `handling-flakiness.md`

Un vrai _retour terrain_, «&nbsp;_Premiers obstacles du monde réel_&nbsp;», très focalisé sur les questions de _flakiness_&nbsp;:

- Aléas serveur (hook `on_failure`).
- Aléas de pas de test (retries internes au POM).
- Aléas de Selenium (`WebDriverException` dans `transient_errors`).
- Erreurs aléatoires discrètes (Watcher).
- Heisenbugs de concurrence (saturate_workers).
